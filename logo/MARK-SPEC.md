# dotBANG mark - FINAL SPEC (settled by the owner, Nov 20, 2026)

One-colour mark. White on black is the primary form; the same geometry in black
is the one-colour form for light surfaces. There is NO blue-dot variant.

## Construction (unit grid, viewBox 190 x 413)

- Stem: full-length straight taper. Top width 72 at y=0, bottom width 62 at
  y=300. Centered over the square (centerline x=154).
- Gap: 36 units everywhere it appears.
- Square (the point): 72 x 72, x=118, y=336..408 (baseline 408).
- Dot: diameter 82, cx=41, cy=372, r=41. Overshoot: 5 above the square's top
  edge and 5 below the baseline, so the circle reads equal to the square.
- Gaps verified equal: horizontal (dot edge to square, measured at the
  square's mid-height, y=372) = 36. Vertical (stem bottom to square top) = 36.

## Rules

- One colour only. Never split the mark into two colours; never a blue dot.
- Clearspace: 1 dot diameter (82 units) on all sides.
- Minimum size: full mark 16px / 6mm tall; below that, use the approved
  small-size tier files (tiers/) rather than scaling ad hoc.
- Never redraw, re-space, or re-taper outside this spec; variants go through
  the render-and-review loop with the owner.
